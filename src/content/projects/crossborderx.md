Dentons is a law firm with offices all over the world. A big cross-border deal moves between countries and time zones, and each handover is a chance for context to get lost.

We built a working prototype in a few days, with a FastAPI backend and a web front end. It scores contract risk, checks compliance against rules for each jurisdiction, suggests which experts in which offices should look at a matter, and writes handoff notes so the next office can pick up where the last one stopped. Every recommendation is logged.

It's rule-based, with no language model in the loop.

We got no result. The code sits in a teammate's private repository.
